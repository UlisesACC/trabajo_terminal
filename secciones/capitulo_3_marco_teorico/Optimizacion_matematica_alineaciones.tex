\subsubsection{Optimización matemática}
La optimización matemática es una rama de las matemáticas
aplicadas orientada a encontrar la mejor solución posible dentro
de un conjunto de alternativas, considerando una función objetivo
y un conjunto de restricciones. Estos problemas pueden formularse
como una maximización o minimización de una función matemática
done representa el criterio que se desea optimizar. \cite{ibm_optimization_model}

De manera general, un problema de maximización se expresa como:

\begin{equation}
    \max_{\mathbf{x} \in \mathcal{F}} f(\mathbf{x}),
\end{equation}

donde:

\begin{itemize}
    \item $\mathbf{x}$ representa el vector de variables de decisión.
    \item $f(\mathbf{x})$ es la función objetivo.
    \item $\mathcal{F}$ representa el conjunto de soluciones factibles.
\end{itemize}

Las soluciones factibles son aquellas que cumplen todas las
restricciones establecidas. La solución óptima corresponde a
aquella que alcanza el mayor valor de la función objetivo dentro
de dicho conjunto.

Cuando las variables de decisión toman valores discretos, como
la selección o exclusión de determinados elementos, el problema
puede estudiarse mediante técnicas de optimización entera o
combinatoria. \cite{boyd2004convex}

\subsubsection{Net Rating}
El Net Rating es una métrica que relaciona la eficiencia ofensiva como defensiva, mediante la diferencia de estos.
$$NetRating=(Defensive_{Rating}-Ofensive_{rating})$$
Notemos que si la métrica indica que durante las posesiones consideradas, el equipo anoto mas puntos que el contrario. La utilidad de esta métrica radica en que compara el rendimiento de diferentes observaciones.
\cite{zuccolotto2020basketball,gaitan_netrating}
\subsubsection{Plus minus}
Para poder medir el efecto individual de los deportes en equipo se hace uso del \textit{plus minus} (PM) sin ajustes.

La función de esta métrica permite identificar el impacto de la jugadora, separando la contribución de sus compañeras, esto se logra calculando la diferencia acumulada entre los puntos que anota el equipo y los que recibe mientras la jugadora se encuentra en la cancha.
$$PM_j=\text{puntos de su equipo mientras juega}- \text{puntos del rival mientras juega}$$

La característica de esta métrica no calcula el impacto cuando estas jugadoras siempre han estado juntas, dado que no identifica la responsable del impacto de esta, por ello se hace uso del \textit{mas-menos ajustado}.

También conviene considerar que es un valor acumulado: el tiempo de participación afecta las oportunidades de acumular diferencias positivas o negativas. El PM básico descrito aquí no está normalizado por minutos o posesiones.
\cite{josephs2025hypergraphadjustedplusminus}

\subsubsection{mas-menos ajustado}
Este enfoque mas-menos ajustado conocido como (APM) ayuda a comparar a jugadores individuales sin dejar de lado a los que juegan juntos; sin embargo no identifica las interacciones entre las jugadoras, esto se da a que una pareja podría funcionar especialmente bien junta y el modelo no tendría un término específico para representarlo.

Para poder calcularlo se hace uso de regresión para estimar la contribución individual, teniendo en cuenta qué otras jugadoras compartieron cancha.

El modelo básico del artículo es:

$$Y=X\beta+\epsilon$$

\begin{itemize}
    \item $Y$ contiene las diferencias de puntos observados para las alineaciones.
    \item $X$ indica que jugadoras integran a cada alineación
    \item $\beta$ contiene las contribuciones individuales de las que se quiere estimar.
    \item $\epsilon$ representa la parte del resultado que el modelo no explica.
\end{itemize}

En cuanto una alineación para 5 jugadoras el modelo supone que:
$$\hat{Y}_{ABCDE}=\hat{\beta}_A+\hat{\beta}_B+\hat{\beta}_C+\hat{\beta}_D+\hat{\beta}_E$$
Por ejemplo, si A suele tener un PM alto porque juega con B, el APM intenta separar sus contribuciones a partir de las distintas alineaciones observadas. Si siempre juegan juntas, los datos dificultan esa separación.

En la bibliografía los autores utilizan el término \textit{alineaciones generalizadas}
para referirse tanto a jugadores individuales como a parejas,
tríos y otras combinaciones de integrantes de un equipo.
Para evaluar estas combinaciones mediante PM y APM, identifican
dos alternativas:

\begin{enumerate}
    \item \textbf{Sumar los valores individuales de APM.}
    Esta alternativa representa el rendimiento de una combinación
    como la suma de las contribuciones estimadas de sus integrantes.
    Su limitación consiste en que no incluye un efecto específico
    asociado a la participación conjunta de dichos jugadores.

    \item \textbf{Calcular el PM acumulado de la combinación.}
    Consiste en obtener la diferencia entre los puntos anotados
    y recibidos durante los intervalos en los que sus integrantes
    participan simultáneamente. Aunque permite describir el
    resultado observado, no ajusta por las otras combinaciones
    presentes en cancha y conserva la sensibilidad a los patrones
    de sustitución.
\end{enumerate}

Estas limitaciones motivan la propuesta de un enfoque que permita
evaluar simultáneamente jugadores y combinaciones de distintos
tamaños. Para ello, los autores emplean una representación
mediante hipergrafos que incorpora las alineaciones completas
y las combinaciones de menor tamaño contenidas en ellas.
Esta representación constituye la base de sus métodos para
estimar contribuciones y analizar posibles sinergias positivas
o negativas entre integrantes de un equipo
\cite{josephs2025hypergraphadjustedplusminus}

\subsubsection{Hipergrafo}
Un hipergrafo $H$, denotado por $H = (V; E = (e_i)_{i \in I})$ sobre un conjunto finito $V$, es una familia $(e_i)_{i \in I}$ ($I$ es un conjunto finito de índices) de subconjuntos de $V$ llamados hiperaristas. A veces $V$ se denota por $V(H)$ y $E$ por $E(H)$.

El orden del hipergrafo $H = (V; E)$ es la cardinalidad de $V$, es decir, $|V| = n$; su tamaño es la cardinalidad de $E$, es decir, $|E| = m$.

Por definición, el hipergrafo vacío es el hipergrafo tal que:

\begin{itemize}
    \item $V = \emptyset$;
    \item $E = \emptyset$.
\end{itemize}

Siempre por definición, un hipergrafo trivial es un hipergrafo tal que:

\begin{itemize}
    \item $V \neq \emptyset$;
    \item $E = \emptyset$.
\end{itemize}
\cite{bretto2013hypergraph}


\subsubsection{Hypergraph Adjusted Plus-Minus (HAMP)}
El Hypergraph Adjusted Plus-Minus (HAPM) amplía el
modelo mas-menos ajustado mediante una representación de las
alineaciones basada en hipergrafos. Su función es estimar las
contribuciones individuales considerando información de
jugadoras, parejas, tríos y otras combinaciones, además de
las alineaciones completas.
\cite{josephs2025hypergraphadjustedplusminus}

Para ello, se utiliza un hipergrafo extendido donde los
vértices representan a las jugadoras y las hiperaristas
representan las combinaciones observadas. Esta se puede representar mediante una matriz de diseño que
se obtiene al transponer la matriz de incidencia de este
hipergrafo. Cada fila corresponde a una combinación y cada
columna a una jugadora:

\begin{equation}
    (X_H)_{ij} =
    \begin{cases}
        1, & \text{si la jugadora } j
             \text{ pertenece a la combinación } i, \\
        0, & \text{en otro caso}.
    \end{cases}
\end{equation}

A diferencia del APM básico, que considera las alineaciones
completas, esta matriz también incluye filas correspondientes
a combinaciones de menor tamaño. Para cada combinación se
utiliza como respuesta su diferencial de puntos acumulado
durante los intervalos en los que sus integrantes
participaron juntas.

El modelo se expresa como (que proviene del mas-menos ajustado):

\begin{equation}
    Y_H = X_H \beta_H + \epsilon.
\end{equation}

\begin{itemize}
    \item $Y_H$ contiene los diferenciales de puntos observados
    para las combinaciones consideradas.
    \item $X_H$ indica qué jugadoras integran cada combinación.
    \item $\beta_H$ contiene las contribuciones individuales
    que se busca estimar.
    \item $\epsilon$ representa la parte del resultado que
    el modelo no explica.
\end{itemize}

Para estimar estas contribuciones se utiliza regresión
Ridge ponderada:

\begin{equation}
    \hat{\beta}_H =
    \underset{\beta}{\operatorname{arg\,min}}
    \left\{
        (Y_H-X_H\beta)^{\mathsf T}
        W(Y_H-X_H\beta)
        + \lambda \|\beta\|_2^2
    \right\}.
\end{equation}

Donde $W$ es una matriz diagonal de pesos asociados al tiempo
de participación conjunta de las combinaciones y $\lambda$
es el parámetro de regularización. La penalización Ridge
permite estabilizar las estimaciones cuando las jugadoras
comparten frecuentemente la cancha o existen combinaciones
con pocas observaciones.
\cite{josephs2025hypergraphadjustedplusminus}

Una vez estimados los coeficientes, se obtienen los valores
ajustados de las combinaciones:

\begin{equation}
    \hat{Y}_H = X_H\hat{\beta}_H.
\end{equation}

Para una combinación formada por las jugadoras
A, B y C, el valor ajustado se calcula como:

\begin{equation}
    \hat{Y}_{ABC} =
    \hat{\beta}_{H,A}
    + \hat{\beta}_{H,B}
    + \hat{\beta}_{H,C}.
\end{equation}

La utilidad de este método consiste en generar clasificaciones
de jugadoras y combinaciones a partir de un mismo modelo.
Para comparar parejas se ordenan los valores ajustados de las
filas que contienen dos jugadoras; el mismo procedimiento
se aplica a tríos y quintetos. Aunque la predicción conserva
una estructura aditiva, los coeficientes se estiman utilizando
información de combinaciones de distintos tamaños.\cite{josephs2025hypergraphadjustedplusminus}
