Las variables de este apartado describen lo que ocurrirá después del corte de predicción. En los datos históricos se conservarán para reconstruir actuaciones, calcular las respuestas y evaluar los modelos; su presencia retrospectiva no las convierte en entradas disponibles para una recomendación. Esta distinción es particularmente importante al buscar el quinteto con mayor Net Rating esperado.

No se completarán estas variables futuras con medias para construir una supuesta actuación del encuentro. Se utilizarán características históricas con nombres diferenciados, obtenidas con datos anteriores, o predicciones de una fase precedente. Imputar una característica histórica ausente es una operación distinta de reemplazar por una media la respuesta futura que se busca predecir \cite{sklearnCommonPitfallsPonderacion}.

La salida \texttt{predicted\_net\_rating} se distinguirá de \texttt{target\_net\_rating}: la primera es una estimación del modelo y la segunda un resultado observado utilizado para evaluación. El procedimiento comparará las estimaciones de los quintetos válidos, conservando restricciones de disponibilidad. Esta selección no vuelve observable el rendimiento de las combinaciones que nunca se utilizaron; la incertidumbre y la cobertura deberán reportarse. La definición de qué se conoce, qué se calcula y qué se predice quedará fijada en este diseño antes de ejecutar la preparación y los experimentos.
