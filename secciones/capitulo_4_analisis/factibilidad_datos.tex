El acceso a datos son distrribuidos atravez de un repositorio de github por wehoop facilitado para desarrollar experimentos reproducibles \cite{wehoopRepositorio}.

Si no se dispone, en las fuentes documentadas que se han seleccionado, de evidencia suficiente para identificar emparejamientos defensivos individuales continuos.
