La tabla tendrá como propósito integrar y organizar la información necesaria para analizar las coincidencias entre jugadoras de equipos contrarios, identificar la procedencia de los registros y facilitar la posterior construcción de las variables que utilizarán los modelos. Esta tabla no se empleará directamente como entrada de los algoritmos, sino que servirá como base para generar los conjuntos de datos requeridos durante las etapas de modelado.
Para cada pareja de jugadoras podrán registrarse ambas perspectivas de análisis, considerando alternativamente a cada participante como jugadora focal. Pero, estos registros no se interpretarán como observaciones independientes ni como evidencia de un emparejamiento defensivo directo, debido a que únicamente representan coincidencias de participación durante determinados intervalos de juego.

La información se organizará considerando como unidad de observación cada combinación de partido, jugadora focal y jugadora rival. Las estadísticas correspondientes se calcularán únicamente a partir de los intervalos en los que ambas jugadoras hayan coincidido en la cancha. Para identificar cada registro, se utilizará una clave compuesta por los campos game\_id, focal\_player\_id y rival\_player\_id. Asimismo, se conservará la fecha del encuentro con la finalidad de mantener un contexto temporal y facilitar la validación cronológica de los datos.

Con el propósito de mantener una nomenclatura uniforme, se utilizará el prefijo rival\_ para identificar las variables correspondientes a la jugadora contraria, sustituyendo durante el procesamiento el prefijo opponent\_ empleado anteriormente. Las relaciones entre los diferentes conjuntos de datos se establecerán mediante identificadores únicos, y se verificara la consistencia de estos datos.
